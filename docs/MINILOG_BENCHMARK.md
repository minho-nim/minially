# 미니로그 경쟁 서비스 비교 (2026-11-25 기준)

경쟁 서비스의 **공개 홈페이지·안내 글**만 읽고 정리했다(로그인·유료 기능은 직접 써 보지 않음). 디자인과 코드는 가져오지 않았다.
"확인"은 공개 페이지에 적혀 있던 것, "미확인"은 지시서에만 있고 페이지에서 찾지 못한 것이다.

## 1. 서비스별 공개 기능

| 서비스 | 공개 페이지에서 확인한 기능 | 미니로그에 가져올 점 |
|---|---|---|
| 블로그이지 (blogeasy.makeus.ai) | 사진 최대 12장, 올린 순서대로 사진 사이에 글. 글 종류 6가지. '한 줄 느낌·참고 내용'에 가격·주차처럼 사진으로 알 수 없는 것을 적게 함. 업로드 때 위치·촬영 정보 지우기. 검색 노출 점수와 '자동으로 고치기'. 크롬 확장으로 네이버·티스토리에 제목·본문·사진·태그 입력, 발행은 직접. 키워드 검색량·경쟁·시즌, 순위 매일 기록, 수익 기록, 제휴 링크. 포인트 결제 | 사진 순서 안내, 참고 내용 칸, 아쉬운 점 한 줄 권장 |
| 개떡찰떡 포스팅 (shotposting.com) | 제휴 링크(쇼핑커넥트·쿠팡파트너스·토스쇼핑·여행커넥트)로 상품 정보·사진·리뷰를 불러와 대가성 문구 넣은 원고. 크롬 확장으로 네이버 블로그·카페·워드프레스 입력. 내 사진 후기, 카드뉴스. 평생 299,000원 | 대가성 문구 자동 점검 |
| 결AI (gyeolai.com) | 내 글 세 편으로 말투 학습. 크롬 확장으로 네이버·티스토리·스레드·인스타 작성기에 입력, 발행은 직접. **무료 '발행 전 검사'**: 글자 수·검색어 횟수·소제목·긴 문단·근거 숫자·AI 글 흔한 표현. "검색 결과 위치를 알려 주는 도구가 아니다"라고 밝힘. 글감 수집함 | 발행 전 점검 항목 구성, 점수의 한계를 화면에 밝히는 방식 |
| PicPost (picpo.app) | 사진 + **사진별 메모**로 초안. "가격·위치·경험 같은 사실은 게시 전에 직접 확인". 자동 게시하지 않음. Windows 프로그램으로 네이버에 제목·본문·이미지 순서대로 입력 | 사진별 메모, 사실 확인 흐름 |
| blogai (blog.ai.kr) | 키워드 검색량·연관·섹션 배치, 통합검색 노출 점검, 포스트 SEO 분석, 금칙어 380+, 맞춤법. 크롬 확장으로 제목·본문·사진·지도·태그 입력. 크레딧 결제 | 금칙어·장소(지도) 입력은 다음 후보 |
| 블로그링커 (bloglinker.app) | Windows 프로그램으로 즉시·예약·임시저장 **자동 발행**. 네이버 로그인 정보를 PC에 저장. 쇼핑·여행커넥트 상품 포스팅, 작업 큐 | 발행 대기열 개념만 참고. 로그인 저장·자동 발행은 **가져오지 않음** |
| 체험ZIP (exp-zip.co.kr) | 레뷰·리뷰노트 등 40곳의 방문형·배송형 공고를 모아 검색(카테고리·지역·마감일·지도). 신청은 원래 사이트에서 | 관심 공고 담기·신청 마감 관리(수집은 하지 않음) |
| 슈블·레드랭크·블로그마스터·뷰토리·블로그랩·블로그온·블로그공장·NVIEW·엔조잇·바이럴메이커 | 이번에 페이지를 읽지 않음 | **미확인** |

## 3. 이번에 하지 않은 것과 이유
- 크롬 확장 입력 보조: 확장을 따로 만들고 배포해야 해서 한 번에 넣기엔 범위가 크다. 다음 작업으로 따로 기획한다.
- 키워드 검색량: 공식 데이터는 네이버 검색광고 API 키가 필요하다(소유자 결정).
- 사진을 장소·음식·제품으로 자동 묶기: Gemini 호출이 늘어난다. 사진 메모로 먼저 확인한 뒤 판단한다.
