# 설계: 미니허브 코드 관리 (보류)

> **2026-11-26 소유자 결정: 보류.** 코드를 바꿀 일이 없어서 만들지 않는다. 기준은 미니허브 `USER_CODE_HASHES` 하나(미니어리 0.1.20부터 세 앱 공통)로 충분하다. 필요해지면 아래 설계로 시작한다.

작성 2026-11-26(한국 시간). 소유자가 정한 방향: **로그인 코드의 주인은 미니허브**. 세 앱(미니허브·미니로그·미니어리)이 같은 코드로 로그인한다.

## 지금 (미니어리 0.1.20 기준)
- **어디서 확인하나:** 코드는 Cloudflare 비밀값 `USER_CODE_HASHES`(`C:해시,D:해시`)에서 확인한다. 미니어리는 예전 `SYNC_CODE_HASHES`도 받는다.
- **코드를 바꾸려면:** 프로젝트 3개의 비밀값을 손으로 고친 뒤 다시 배포해야 한다.
- **미니어리 데이터 위치:** 코드 해시 앞 16자(`space`)다. 그래서 **코드를 바꾸면 기존 일정·메모가 안 보인다.**

## 목표
1. 미니허브 '설정 → 코드 관리'에서 사람마다 코드를 **추가·바꾸기·끊기**를 한다. 그러면 세 앱에 바로 적용된다(재배포 없음).
2. 코드를 바꿔도 미니어리 데이터는 그대로 보인다.
3. 코드 원문은 어디에도 저장하지 않는다. 해시만 저장한다(저장소 보안 규칙 그대로).

## 표 1개 추가 (공용 D1, 기존 표는 건드리지 않음)
```sql
CREATE TABLE IF NOT EXISTS hub_codes (
  hash TEXT PRIMARY KEY,          -- 코드 SHA-256(정규화 후)
  user TEXT NOT NULL,             -- 'C' | 'D'
  space TEXT NOT NULL,            -- 미니어리 데이터 공간(처음 코드의 해시 앞 16자, 코드를 바꿔도 그대로)
  label TEXT NOT NULL DEFAULT '', -- 예: '폰', 'PC'
  created_at INTEGER NOT NULL,
  revoked_at INTEGER              -- 끊은 코드(NULL이면 사용 중)
);
```
- **데이터를 옮기지 않는 이유:** `space`를 표에 적어 두기 때문이다. 새 코드도 같은 `space`를 가리키게 하면 기존 데이터가 그대로 열린다.

## 로그인 확인 순서 (세 앱 공통 `userForCode`/`spaceFor`)
1. `hub_codes`에서 해시를 찾는다(끊긴 것 제외). 있으면 그 `user`와 `space`를 쓴다.
2. 없으면 지금처럼 비밀값(`USER_CODE_HASHES`·`SYNC_CODE_HASHES`)을 본다. 바꾸는 동안 로그인이 끊기지 않게 하기 위해서다.

## 미니허브 화면 (로그인한 사람: 자기 코드만, 소유자: 둘 다)
- **목록:** 코드 목록에는 라벨·만든 날·마지막 사용만 보이고, 코드는 보이지 않는다.
- **새 코드 만들기:** 서버가 무작위 코드를 만들어 **한 번만** 화면에 보여 주고, 해시만 저장한다.
- **끊기:** `revoked_at`을 적는다. 끊으면 그 코드의 세션도 지운다.

## 보안
- **요청 검사:** 모든 요청에 `requireSession`, `sameOrigin`, `bind()`를 쓰고, 다른 사람 줄은 못 바꾼다(`user = ?`).
- **비밀값 코드 보호:** 비밀값에 있던 코드는 표에 없으니, 화면에서는 '비밀값 코드(바꾸려면 새 코드 만든 뒤 비밀값에서 빼기)'로만 보여 준다.
- **틀린 코드:** 틀린 코드 제한은 지금처럼 IP당 10분이다.

## 순서 (승인 뒤, PR 2개)
1. **PR 1:** 표와 확인 순서(비밀값을 뒤에 두고 같이 봄)와 시험.
   - 화면은 만들지 않는다. 운영에는 표만 생긴다.
2. **PR 2:** 허브 '코드 관리' 화면과 시험.
   - 처음 코드를 만들 때 지금 쓰는 코드의 `space`를 이어받게 한다. 사람마다 지금 코드를 한 번 넣어 '이 코드의 데이터 이어받기'를 누른다.
   - 운영 DB 변경은 `CREATE TABLE IF NOT EXISTS` 하나뿐이다(소유자 승인 필요).

## 정할 것 (소유자)
- 다른 사람(C↔D) 코드를 서로 볼 수 있게 할지, 각자 자기 것만 볼지
- 바꾸기 전 코드를 바로 끊을지, 며칠 같이 둘지
