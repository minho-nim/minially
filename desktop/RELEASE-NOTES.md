미니어리 Windows V.0.1.6

- 업데이트 중에는 기본 설치 마법사 대신 앱 아이콘·로즈 배경·둥근 모서리·핑크색 진행 표시가 있는 작은 테마 창을 보여 줍니다. 실제 설치가 끝나면 창이 닫히고 앱이 자동으로 열립니다. 표시용 가짜 진행률은 사용하지 않습니다.
- Ctrl+휠 또는 Ctrl+플러스/마이너스로 실제 화면 배율을 50~150% 사이에서 조절합니다. Ctrl+0 또는 상단 배율 표시를 누르면 기본 100%로 돌아갑니다. 배율은 기기에 저장하며 제목 표시줄은 같은 크기를 유지합니다.
- 메모 분류 설정에 삭제 기능을 추가했습니다. 분류 안의 메모와 휴지통 메모는 내용을 유지한 채 미분류로 옮기며, 할 일·일정의 원문 연결도 유지합니다. 분류 삭제는 다른 기기와 동기화됩니다.
- 메모 서식 도구의 아이콘·선택 상자를 조금 줄였습니다. 모바일 터치 영역은 유지합니다.
- PC 메모 화면의 이중 스크롤을 없애고 가장자리의 불필요한 스크롤바를 숨겼습니다. 편집 내용은 휠·키보드로 계속 스크롤할 수 있습니다.
- 모바일 메모와 설정 입력 글자의 최소 크기를 조정해 입력 시 자동 확대되는 원인을 줄였습니다. 기존 메모의 저장된 서식은 변경하지 않습니다.

Windows 10·11 64비트, 사용자 계정 설치를 지원합니다. 업데이트 테마 창은 Windows 기본 .NET 구성 요소로 작동하며 기록·네트워크·설치 파일에 접근하지 않습니다.
설치 파일은 코드 서명 인증서가 없는 상태입니다. Windows 게시자 확인 경고는 나타날 수 있으며 HTTPS·SHA512 업데이트 검증을 유지합니다.
