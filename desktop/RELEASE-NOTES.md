미니어리 Windows 0.1.1

- 메모 → 휴지통에 **휴지통 비우기**를 추가했습니다. 확인 후 휴지통의 메모를 영구 삭제하며, 연결된 할 일과 일정은 유지합니다.
- 확인창을 연 뒤 다른 창에서 복원하거나 수정한 메모는 보호합니다.
- 오프라인에서 비운 휴지통도 다시 연결되면 같은 코드의 다른 기기에 반영됩니다.

캘린더·할 일·메모를 Windows 앱으로 사용할 수 있습니다. PC 웹도 계속 사용할 수 있으며, 같은 연결 코드를 입력하면 기존 기록과 동기화합니다.

- `Minially-Setup.exe`를 내려받아 설치하세요. Windows 10·11 64비트를 지원하며 사용자 계정에 설치합니다.
- Ctrl+Alt+M으로 빠른 메모를 열고, 트레이 메뉴에서 전체 창·빠른 메모·항상 위를 사용할 수 있습니다.
- 설정 → 앱 설치에서 로그인 시 실행, 항상 위, 자동 업데이트를 설정합니다. 재시작 전 모든 창의 저장 상태를 확인합니다.
- 오프라인에서는 기기에 저장하고 다시 연결되면 동기화합니다. 같은 메모의 동시 수정은 충돌 사본으로 보존합니다.
- 분류는 직접 추가하며, 내용과 기존에 분류한 메모를 참고해 추천합니다. 추천을 눌러야 적용됩니다.

Windows 설치 파일은 코드 서명 인증서가 없는 상태입니다. Windows에서 게시자 확인 경고가 나타날 수 있습니다. 회사 보안 정책에 따라 설치가 제한될 수 있으며, 기존 웹 버전은 계속 사용할 수 있습니다. 자동 업데이트는 HTTPS와 SHA512 검증을 사용합니다.
