미니어리 Windows V.0.1.5

- Windows 바탕화면·작업 표시줄 아이콘의 모서리를 투명하게 처리해 둥글게 표시합니다. 창 왼쪽의 빨강·노랑·초록 제어 원도 조금 줄였습니다.
- 상단 키보드 버튼에서 단축키 목록을 바로 볼 수 있습니다. 메모 편집과 Windows 빠른 메모 단축키도 함께 안내합니다.
- 메모의 글자색·강조색을 테마 색상표, 표준 색, 직접 색 선택으로 변경합니다.
- 글꼴을 맑은 고딕·돋움·굴림·바탕·궁서·Arial·Georgia·Courier New로 확장했습니다. 기기에 설치된 글꼴을 사용하며 없으면 기본 글꼴로 표시합니다.
- 메모 편집기 톱니바퀴 또는 설정 → 메모에서 기본 글꼴·크기·글자색·줄간격·강조색을 저장합니다. 새 메모에 적용하고 기존 메모의 서식은 유지합니다. 설정과 메모별 기본 서식은 같은 연결 코드로 동기화합니다.
- 작은 창에서 메모 하단 등록 영역까지 스크롤할 수 있도록 개선했습니다. 메모 설정과 단축키 창도 낮은 화면에서 끝까지 볼 수 있습니다.
- 업데이트를 누르면 저장 확인 상태를 즉시 표시합니다. 새 버전 적용 중에는 ‘미니어리 업데이트 중’ 진행 창을 보여 주고 완료 후 앱을 자동으로 엽니다. 다운로드 후 모든 창의 저장 상태를 확인하는 보호 기능은 유지합니다.

Windows 10·11 64비트를 지원하며 사용자 계정에 설치합니다. Ctrl+Alt+M으로 빠른 메모를 열고 트레이에서 항상 위를 사용할 수 있습니다. PC 웹과 모바일도 같은 연결 코드로 동기화합니다.
설치 파일은 코드 서명 인증서가 없는 상태입니다. Windows 게시자 확인 경고가 나타날 수 있습니다. 자동 업데이트는 HTTPS와 SHA512 검증을 사용합니다.
