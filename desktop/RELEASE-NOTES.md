미니어리 Windows V.0.1.2

- Windows 기본 제목 표시줄을 맥 스타일 상단 바로 바꿨습니다. 왼쪽 빨강·노랑·초록 버튼으로 창 닫기·최소화·최대화 및 복원을 할 수 있습니다.
- 상단 바를 잡아 창을 이동할 수 있고, 빠른 메모 창에도 같은 디자인을 적용했습니다.
- 상단 오른쪽의 **V.0.1.2**를 누르면 버전 정보와 자동 업데이트 상태를 볼 수 있습니다. 다운로드 진행률과 새 버전 준비 상태도 표시합니다.
- 앱 시작 시와 실행 중에 새 버전을 자동 확인하며, 인터넷이 다시 연결되면 확인을 재시도합니다. 기본 설정은 자동 다운로드입니다.
- 업데이트를 받아도 작성 중 강제 종료하지 않습니다. **저장 후 재시작**으로 열린 창의 저장 상태를 확인한 뒤 설치합니다.
- 메모의 분류·목록 사이 경계선을 드래그하거나 키보드로 폭을 조절하고 기기별로 기억합니다. 두 번 누르면 기본 폭으로 돌아옵니다.
- 메모 내용에서 기존 분류를 추천하고, **내용에서 여러 항목 등록**으로 문장을 나눠 할 일·일정의 제목·날짜·시간·카테고리를 제안합니다. 추천은 날짜 표현·키워드·기존 메모를 참고하며 자동으로 등록하지 않습니다.
- 추천 항목을 수정·선택해 한 번에 30개까지 등록합니다. 원본 연결을 유지하고, 중복·부분 저장을 막으며 실행 취소를 지원합니다.
- 메모 휴지통 비우기와 기존 캘린더·할 일·동기화 기능은 계속 사용할 수 있습니다.

캘린더·할 일·메모를 Windows 앱으로 사용할 수 있습니다. PC 웹도 계속 사용할 수 있으며, 같은 연결 코드를 입력하면 기존 기록과 동기화합니다.

- `Minially-Setup.exe`를 내려받아 설치하세요. Windows 10·11 64비트를 지원하며 사용자 계정에 설치합니다.
- Ctrl+Alt+M으로 빠른 메모를 열고, 트레이 메뉴에서 전체 창·빠른 메모·항상 위를 사용할 수 있습니다.
- 설정 → 앱 설치에서 로그인 시 실행, 항상 위, 자동 업데이트를 설정합니다. 재시작 전 모든 창의 저장 상태를 확인합니다.
- 오프라인에서는 기기에 저장하고 다시 연결되면 동기화합니다. 같은 메모의 동시 수정은 충돌 사본으로 보존합니다.
- 분류는 직접 추가하며, 내용과 기존에 분류한 메모를 참고해 추천합니다. 추천을 눌러야 적용됩니다.

Windows 설치 파일은 코드 서명 인증서가 없는 상태입니다. Windows에서 게시자 확인 경고가 나타날 수 있습니다. 회사 보안 정책에 따라 설치가 제한될 수 있으며, 기존 웹 버전은 계속 사용할 수 있습니다. 자동 업데이트는 HTTPS와 SHA512 검증을 사용합니다.
