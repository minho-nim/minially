미니어리 Windows V.0.1.7

- 설정의 ‘메모’ 탭 이름을 ‘메모 서식’으로 바꿨습니다. 새 메모의 기본 글꼴·크기·색상을 설정하는 기능은 그대로 유지합니다.
- 앞으로 웹과 Windows 앱은 같은 소스·버전으로 함께 배포합니다. Windows 앱의 검사·공개가 끝난 뒤 웹 배포를 시작하며, 앱 배포가 준비되지 않으면 웹 운영 배포를 중단합니다.

Windows 10·11 64비트, 사용자 계정 설치와 자동 업데이트를 지원합니다.
설치 파일은 코드 서명 인증서가 없는 상태입니다. Windows 게시자 확인 경고는 나타날 수 있으며 HTTPS·SHA512 업데이트 검증을 유지합니다.
