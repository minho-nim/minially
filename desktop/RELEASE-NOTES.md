미니어리 Windows V.0.1.4

- 메모에서 할 일을 등록하면 설정창에서 제목·날짜·카테고리·우선순위·메모·체크리스트를 확인하고 수정할 수 있습니다.
- 본문에서 선택한 문장이 있으면 선택 내용을, 없으면 메모 전체를 채웁니다. 폴더의 기본 카테고리도 적용하며 원본 메모는 유지합니다.
- 일정은 기존 등록창에서 날짜·여러 날짜·시간·종일·카테고리·반복·메모를 설정합니다. 상세 옵션에 일정별 알림을 추가해 공통 설정을 따르거나 별도로 지정할 수 있습니다.
- 메모의 분류·목록·편집기를 작은 간격과 개별 라운드로 분리했습니다. 드래그·키보드 폭 조절은 유지합니다.
- 앱 시작 시 새 버전을 자동 확인하고 상단 오른쪽 V.0.1.4 옆에 새 버전·다운로드 진행률·재시작 준비 상태를 표시합니다. 자동 팝업은 띄우지 않습니다.
- 저장 후 재시작을 누르면 모든 창의 저장 상태를 확인한 뒤 설치 진행창 없이 업데이트합니다. 기존 버전에서 이 버전으로 업데이트할 때도 적용합니다. 직접 실행한 첫 설치는 기존 설치 화면을 유지합니다.
- 브랜드 옆 중복 동기화 점은 제거했습니다. 동기화 상태는 설정에서 계속 확인할 수 있습니다.

Windows 10·11 64비트를 지원하며 사용자 계정에 설치합니다. Ctrl+Alt+M으로 빠른 메모를 열고 트레이에서 전체 창·빠른 메모·항상 위를 사용할 수 있습니다.
PC 웹과 모바일도 같은 연결 코드로 동기화합니다. 알림은 기기 권한이 필요하며 앱이 실행 중일 때 작동합니다.
Windows 설치 파일은 코드 서명 인증서가 없는 상태로 게시자 확인 경고가 나타날 수 있습니다. 설치 진행창 숨김과 Windows 보안 경고는 별개이며, 자동 업데이트의 HTTPS·SHA512 검증은 유지합니다.
