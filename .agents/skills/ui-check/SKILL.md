# 화면 확인

> **minoffia 메모:** 미노피아가 만든 스킬. 예전에 지시서의 '화면 확인'·'디자인 원칙' 절로 붙던 것을 옮겼다.

## 지시서용 요약

- 데스크톱(1400px)·휴대폰(400px) 폭에서 직접 열어 보고, 콘솔 오류·가로 넘침이 없는지 결과에 적는다. 클라우드 세션에 Playwright가 있으면 그것으로 스크린샷을 만든다(저장소에 커밋하지 않음).
- 불러오는 중·빈 화면·오류 상태와 아주 긴 글자(넘침)를 함께 확인한다. 키보드로도 쓸 수 있게 한다.
- 이미 있는 색·글꼴·간격 규칙(CSS 변수 등)을 그대로 쓰고, 글자 대비와 손가락으로 누르기 쉬운 버튼 크기(44px 안팎)를 지킨다.
- 새 디자인·꾸미기 일이면: 흔한 AI 꾸밈(보라·파랑 그라데이션, 그라데이션 글자, 유리 효과, 의미 없는 장식)을 쓰지 않는다. 카드 안에 카드를 넣지 않는다. 주 색 하나와 중립색, 글자 크기 3~4단계, 간격 4·8px 배수. 한 번에 보이는 선택지가 4개를 넘으면 묶거나 접는다.
