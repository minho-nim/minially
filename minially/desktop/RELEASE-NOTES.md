미니어리 Windows V.0.1.14

- 달력 일정 이름을 3글자로 자르지 않고 칸 너비만큼(휴대폰에서 5글자 안팎) 보여 줍니다. 일정 글자는 차분한 색과 보통 굵기로, 토요일은 파란색으로 바뀌었습니다.
- '대체공휴일'처럼 긴 공휴일 이름도 좁은 화면에서 잘리지 않습니다.
- 주간 달력 일정에도 카테고리 색이 보입니다.
- 화면 위와 설정 > 앱 설치의 아이콘이 앱 아이콘(달력 모양)으로 바뀌었습니다.
- 달력을 넘길 때 손가락을 더 부드럽게 따라가고, 넘긴 뒤 멈칫하는 순간을 줄였습니다(앞뒤 달을 미리 그려 둔 그대로 옮겨 씀).
- 설정의 '기본 데이터로 초기화' 버튼과 설정 > 카테고리의 '새 카테고리 추가' 칸을 뺐습니다(카테고리는 달력의 '카테고리' 버튼이나 일정 등록 창에서 추가).

Windows 10·11 64비트, 사용자 계정 설치와 자동 업데이트를 지원합니다.
설치 파일은 코드 서명 인증서가 없는 상태입니다. Windows 게시자 확인 경고는 나타날 수 있으며 HTTPS·SHA512 업데이트 검증을 유지합니다.
