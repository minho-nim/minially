미니어리 Windows V.0.1.17

- 사진으로 일정 넣기: 새 일정 창의 '사진으로' 버튼이나 날짜 창 빠른 입력의 사진 아이콘으로 예약 문자·공지·포스터 사진을 고르면, 날짜와 시간을 찾아 일정 후보로 보여 줘요. 고치고 체크한 것만 한 번에 등록되고, 되돌리기도 한 번에 돼요.
- 같은 시간에 다른 일정이 있으면 알려 주고, 연도처럼 짐작한 날짜는 '확인 필요'로 표시해 처음엔 꺼 둬요.
- 사진은 저장하지 않아요. 위치·촬영 정보를 지운 뒤 읽고 바로 버려요.
- 쓰지 않던 '기본 데이터로 초기화' 코드를 정리했어요.

Windows 10·11 64비트, 사용자 계정 설치와 자동 업데이트를 지원합니다.
설치 파일은 코드 서명 인증서가 없는 상태입니다. Windows 게시자 확인 경고는 나타날 수 있으며 HTTPS·SHA512 업데이트 검증을 유지합니다.
