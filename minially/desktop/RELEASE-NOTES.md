미니어리 Windows V.0.1.11

- 메모에 사진을 넣을 수 있습니다(편집기의 '사진 넣기', 붙여넣기, 끌어다 놓기). 사진은 자동으로 줄여 저장하고 다른 기기와 동기화됩니다.
- 메모 '수정 기록': 고치기 전 내용을 이 기기에 남겨 두고, 비교해 보고 이전 버전으로 되돌릴 수 있습니다(메모당 최근 30개).
- 백업 복원이 기본으로 '합치기'가 되었습니다. 지금 데이터는 지우지 않고, 없는 항목은 더하고 더 최신인 항목만 바꿉니다. 복원 직전에 지금 데이터를 자동으로 백업 파일로 받아 둡니다.
- 사진이 들어간 메모를 이전 버전 앱에서 받으면 동기화가 멈출 수 있습니다. 모든 기기를 이 버전으로 업데이트해 주세요.

Windows 10·11 64비트, 사용자 계정 설치와 자동 업데이트를 지원합니다.
설치 파일은 코드 서명 인증서가 없는 상태입니다. Windows 게시자 확인 경고는 나타날 수 있으며 HTTPS·SHA512 업데이트 검증을 유지합니다.
