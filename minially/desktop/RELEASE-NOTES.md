미니어리 Windows V.0.1.13

- 달력의 공휴일 이름이 날짜 숫자 아래 줄에 빨간 글씨로 보입니다(예: 설날, 대체공휴일). 이름이 있는 주는 칸마다 같은 높이를 비워 두어 이어진 일정 막대가 어긋나지 않습니다.
- 설·추석은 '설 연휴 / 설날 / 설 연휴', '추석 연휴 / 추석 / 추석 연휴'로 나눠 보여 줍니다.

Windows 10·11 64비트, 사용자 계정 설치와 자동 업데이트를 지원합니다.
설치 파일은 코드 서명 인증서가 없는 상태입니다. Windows 게시자 확인 경고는 나타날 수 있으며 HTTPS·SHA512 업데이트 검증을 유지합니다.
