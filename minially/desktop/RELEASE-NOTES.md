미니어리 Windows V.0.1.9

- 저장소 이름이 미니허브(minihub)로 바뀌어, 앱 업데이트와 설치 파일을 새 주소에서 받습니다. 앱 기능·데이터·동기화 주소는 그대로입니다.
- 0.1.8 이하에서 자동 업데이트가 되지 않으면 설정의 'Windows 앱 다운로드'로 새로 설치해 주세요(데이터는 동기화로 그대로 이어집니다).

Windows 10·11 64비트, 사용자 계정 설치와 자동 업데이트를 지원합니다.
설치 파일은 코드 서명 인증서가 없는 상태입니다. Windows 게시자 확인 경고는 나타날 수 있으며 HTTPS·SHA512 업데이트 검증을 유지합니다.
