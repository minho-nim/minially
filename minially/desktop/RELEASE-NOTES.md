미니어리 Windows V.0.1.20

- 새 버전 알림: 앱을 켜고 3초 뒤 새 버전을 확인해요. 받아져 있으면 화면 아래에 '새 버전 준비됨 · 지금 재시작'을 한 번 보여 줘요(재시작 전에 저장 상태를 확인해요).
- 업데이트 뒤 처음 켜면 '새 버전으로 바뀌었어요'와 바뀐 점을 한 번 보여 줘요.
- 로그인 코드 기준을 미니허브로: 미니허브에 등록된 코드면 미니어리에도 로그인돼요. 쓰던 코드와 데이터는 그대로예요.
- 웹·폰에서도 켤 때 새 버전이 있으면 '새로고침'으로 바로 받을 수 있어요.

Windows 10·11 64비트, 사용자 계정 설치와 자동 업데이트를 지원합니다.
설치 파일은 코드 서명 인증서가 없는 상태입니다. Windows 게시자 확인 경고는 나타날 수 있으며 HTTPS·SHA512 업데이트 검증을 유지합니다.
