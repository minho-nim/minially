미니어리 Windows V.1.24.1

- 버전 번호를 MinLab 개발일지 번호와 맞췄어요(이전 V.0.1.21 다음 판이에요). 설치된 앱은 그대로 업데이트돼요.
- 글로 넣기: '두 시 반'·'열한 시'처럼 글자로 쓴 시간, 정오·자정, '다음 달 3일'·'이번 달 30일'·'오는 28일'·'다다음 주 월요일'을 읽어요.
- 글로 넣기: 네이버·카카오 예약 알림은 앱 이름 대신 업체명을 제목으로, '■ 예약일시' 줄도 읽어요. '12/3~12/5 여행'은 여러 날 일정 하나로 넣어요.
- 사진으로 넣기: 사진 속 글자를 먼저 옮겨 적은 뒤 일정을 찾고, 그 글로 날짜·시간을 한 번 더 확인해요. 글에 없는 날짜는 '확인 필요', 빠진 날짜는 더해 줘요. 작은 글자도 읽히게 사진을 조금 더 크게 보내요.
- 여러 날 일정을 등록하면 '일정 N개(M일)를 넣었어요'로 알려 줘요.

Windows 10·11 64비트, 사용자 계정 설치와 자동 업데이트를 지원합니다.
설치 파일은 코드 서명 인증서가 없는 상태입니다. Windows 게시자 확인 경고는 나타날 수 있으며 HTTPS·SHA512 업데이트 검증을 유지합니다.
