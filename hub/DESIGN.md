# 미니 가족 디자인 기준 (미니허브·미니로그, 미니어리와 맞춤)

참고: Vercel·Mercury·Notion (대시보드 구조만 참고, VoltAgent/awesome-design-md MIT). 캐릭터·로고·색은 미니 가족 것.

## 정체성
- **캐릭터 '토몽이'**: 새싹 달린 동글동글 토마토. 앱마다 색만 바꿔 입는다. 그림은 `shared/ui/tomong.ts`(SVG 코드).
  - 미니허브: 코랄 `#FFAA9C` · 미니어리: 분홍 `#F4A3BB` · 미니로그: 살구 `#FFBE85`
  - 앱 아이콘은 여백을 줄여 토몽이가 아이콘의 약 90%를 채우게(발은 뺌), 24px 미만은 얼굴 없이 형태만.
  - 등장하는 곳: 로그인, 첫 인사, 빈 화면, AI 작업 중(통통 튀는 움직임, 움직임 줄이기 설정이면 멈춤). 숫자·표 옆에는 넣지 않는다.
- **손글씨 서명 로고(A안)**: 토몽이 + `mini`(Caveat) + 앱 글자(hub·ally·log, 앱 색). 작은 곳은 토몽이만.
- **앱별 손글씨(한 줄 말)**: 미니허브 Gaegu, 미니로그 Nanum Pen Script, (미니어리 Hi Melody 예정). 글꼴 파일은 앱에 직접 넣음(@fontsource, SIL OFL), 외부 글꼴 서버 요청 없음.
- 역할 나누기: 귀여움·감성 = 캐릭터·손글씨 / 깔끔 = 숫자·표·입력 칸은 반듯한 본문 글꼴 / 과감 = 토마토 서명 색 타일 하나·큰 숫자.

버튼은 잉크색 바탕 + 흰 글자(대비 확보). 토마토 색 위 흰 글자는 큰 글자(24px 이상 굵게)에만.

## 화면 구조(대시보드)
- PC(≥ 900px): 왼쪽 메뉴 + 본문. 휴대폰: 위쪽 막대 + 가로로 넘기는 메뉴.
- 미니허브 본문: 토몽이 인사 카드 → 숫자 타일 4개(Gemini 연결 타일만 토마토 색) → 앱 카드(앱 색 바탕 + 토몽이 + 손글씨 로고) → 앱별 사용량(앱 색 막대) → 설정.
- 미니로그: 왼쪽 원고 목록 + 1 사진 · 2 경험 · 3 원고 단계 카드.

## 바닥 규칙
- 보라·파랑 그라데이션, 카드 안 카드, 이모지 아이콘, 지어낸 숫자 금지(숫자는 서버 값만).
- 버튼·링크 높이 44px 이상(메뉴 40px), 본문 글자 대비 4.5:1 이상.
