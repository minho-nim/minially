# 미니허브 디자인 기준

참고: Vercel·Mercury·Notion (구조만 참고, VoltAgent/awesome-design-md MIT). 색·이름은 미니허브 것.

## 화면 구조(대시보드)
- PC(≥ 900px): 왼쪽 메뉴(240px, 고정) + 오른쪽 본문. 휴대폰: 위쪽 막대 + 가로로 넘기는 메뉴.
- 본문 순서: 인사·날짜 → 숫자 타일 4개(호출·토큰·오류·Gemini) → 앱 카드 → 앱별 사용량 막대·표 → 계정·연결 설정.
- 카드: 흰 바탕 + 얇은 선(1px), 그림자는 거의 없음. 앱 카드만 앱 색을 옅게 깐 머리띠.
- 숫자 타일: 큰 숫자(28px, 굵게, 숫자 폭 고정) + 작은 이름표.

## 글자
- 한글 시스템 글꼴(Pretendard가 있으면 Pretendard, 없으면 Apple SD Gothic Neo·맑은 고딕).
- 크기 단계: 13 / 14 / 16(본문) / 20(구역 제목) / 28(숫자 타일).

## 바닥 규칙
- 보라·파랑 그라데이션, 카드 안 카드, 이모지 아이콘, 지어낸 숫자 금지(숫자는 서버 값만).
- 버튼·링크 높이 44px 이상, 글자 대비 4.5:1 이상.
