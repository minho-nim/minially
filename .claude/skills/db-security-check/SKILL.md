# DB·보안 확인

> **minoffia 메모:** 미노피아가 만든 스킬. 예전에 지시서의 'DB 변경 확인'·'보안 확인' 절로 붙던 것을 옮겼다.

## 지시서용 요약

DB
- 스키마 변경은 새 마이그레이션 파일로만 하고, 이미 있는 마이그레이션 파일은 그대로 둔다.
- 새 표는 RLS를 켜고 소유자 조건 정책을 함께 만든다(USING(true) 전체 허용 금지).
- 되돌리기 어려운 변경(열 삭제·이름 변경)은 데이터를 지키는 방법과 함께 남은 문제에 적고, DB 시험이 있으면 돌린다.

보안
- 권한 검사는 서버에서 하고, 화면에서 숨기는 것은 편의로만 쓴다. 권한은 서버가 정한 값으로 판단한다(user_metadata로 판단하지 않음).
- 비밀값·토큰은 서버 비밀 설정에서만 읽고 응답·로그·화면에는 가린다. 브라우저 환경 변수(VITE_·NEXT_PUBLIC_)에는 공개 키만.
- 로그인 안 됨·권한 없음 경우를 시험으로 확인한다.
