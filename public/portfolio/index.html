일정·할 일·자주 쓰는 문구를
한 화면에 모은 달력 앱

미니어리는 달력, 할 일, 자주 쓰는 문구(프리셋)를 한곳에서 관리하는 앱입니다. 코딩 지식 없이 AI와 대화하며 17일 동안 만들었습니다.

PC에서는 설치한 앱처럼 열고, 휴대폰과는 같은 코드로 로그인해 자동으로 맞춰집니다.

혁신가

바꾸고 싶었던 것

일정·할 일·자주 쓰는 문구를 한곳에서 관리하고 싶었습니다. PC에서는 메모장처럼 바로 열어 쓰고, 휴대폰과는 따로 옮기지 않아도 맞춰지길 바랐습니다.
  • 전달력 앱, 할 일 앱, 메모가 따로 있었습니다.후하루를 누르면 그날 일정과 할 일을 같이 봅니다.
  • 전'영어 학원' 같은 일정을 매번 다시 입력했습니다.후자주 쓰는 문구를 프리셋으로 저장해 눌러서 넣습니다.
  • 전PC와 휴대폰 기록이 따로 놀았습니다.후같은 코드로 로그인하면 30초마다 자동으로 맞춰집니다.

어떻게 쓰나

  • 달력에서 바로 등록

    날짜를 누르면 그날 일정이 뜨고, 아래 입력창에서 바로 등록합니다. 월간·주간을 옆으로 밀어 넘깁니다.

  • 프리셋(자주 쓰는 문구)

    자주 쓰는 일정 이름을 그룹으로 모아 두고, 눌러서 제목에 넣습니다. 즐겨찾기·사용 순 정렬이 됩니다.

  • 할 일

    하루·기간·이번 주로 봅니다. 끝내지 못한 할 일은 '미완료 가져오기'로 오늘로 옮깁니다.

  • PC·휴대폰 자동 맞춤

    받은 코드로 한 번 로그인하면 다음부터 자동 로그인됩니다. 인터넷이 끊겨도 기기에 먼저 저장합니다.

  • 같이 보기

    보기 전용 공유 코드를 주고받아 상대 일정을 내 달력에 겹쳐 봅니다. 사람마다 켜고 끕니다.

질문 1. 두 기기에서 고친 내용이 다르면 어느 쪽이 맞을까?

  • 항목마다 마지막에 저장한 값이 이기게 했습니다.
  • 인터넷이 끊겨도 먼저 기기 안에 저장하고, 다시 연결되면 바뀐 항목만 서버와 맞춥니다.
  • 두 기기에서 같은 일정을 동시에 고치는 경우는 아직 탐구 중입니다. (만드는 중)

질문 2. 누가 로그인 코드를 알아내려 하면?

  • 서버는 코드 원문 대신 SHA-256 해시만 가집니다.
  • 10분에 20번 틀리면 그 접속을 막습니다.
  • 체험 모드는 서버에 아무것도 보내지 않습니다.

질문 3. 코딩을 모르는데 잘 됐는지 어떻게 알지?

  • 사람 대신 자동 시험 101개가 확인합니다.
  • 시험이 하나라도 실패하면 운영에 올리지 않습니다.
  • 실제 아이폰에서 직접 확인하는 일은 아직 남았습니다. (만드는 중)

문제

  • 같은 일정을 매번 다시 적어야 했습니다.
  • PC와 휴대폰 기록이 따로 놀았습니다.

해결

  • 자주 쓰는 문구를 프리셋으로 저장해 눌러서 입력합니다.
  • 같은 코드로 로그인하면 PC와 휴대폰이 자동으로 맞춰집니다.
  • 추가 비용 0원으로 운영합니다.
